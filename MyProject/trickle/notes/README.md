# پروژه پلتفرم بازی‌های آنلاین

## توضیحات کلی
این پروژه یک پلتفرم کامل برای بازی‌های آنلاین است که شامل سیستم احراز هویت و مدیریت کاربران می‌باشد.

## صفحات پروژه
- **index.html**: صفحه اصلی و نمایش لیست بازی‌ها
- **login.html**: صفحه ورود به حساب کاربری
- **register.html**: صفحه ثبت نام کاربران جدید
- **forgot-password.html**: صفحه بازیابی رمز عبور
- **profile.html**: صفحه پروفایل کاربری
- **game.html**: صفحه بازی حدس عدد (نمونه)

## ویژگی‌های فعلی
- سیستم احراز هویت کامل (ورود، ثبت نام، فراموشی رمز)
- ذخیره‌سازی اطلاعات در دیتابیس Trickle
- سیستم امتیازدهی و رکوردگیری بازی‌ها
- نمایش آمار بازیکن (امتیاز کل، تعداد بازی، رکوردها)
- بازی پاپ به عنوان بازی اصلی و محبوب (در انتظار قوانین)
- بازی‌های اضافی: حدس عدد، مار، 2048، حافظه، دوز
- طراحی مدرن و ریسپانسیو با TailwindCSS

## طراحی و استایل
- رنگ اصلی: بنفش (#8b5cf6)
- رنگ ثانویه: فیروزه‌ای (#06b6d4)
- طراحی: مدرن با گرادیانت‌های نرم

## برنامه توسعه آینده
- تکمیل بازی پاپ (در انتظار دریافت قوانین از کاربر)
- سیستم رتبه‌بندی جهانی بازیکنان
- سیستم جوایز و پاداش
- بازی‌های چند نفره آنلاین
- اضافه کردن تاریخچه دقیق‌تر بازی‌ها
